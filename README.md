# Punto de Venta — descargas y actualizaciones

Aquí se publican los instaladores del Punto de Venta. El programa instalado revisa este
repositorio para saber si hay una versión nueva y actualizarse solo.

## Instalar por primera vez

1. Entra a **Releases** (a la derecha de esta página) y abre la versión más reciente.
2. Descarga el archivo `PuntoDeVenta-Instalador-<versión>.exe` y ábrelo.
3. Si Windows muestra una advertencia, elige **Más información → Ejecutar de todas formas**.

## Actualizar

No hay que hacer nada: el programa busca versiones nuevas al abrirse, las descarga sin interrumpir
la venta y las instala al cerrarse (antes guarda un respaldo de los datos). También se puede instalar
al momento desde **Ajustes → Sistema y respaldos → Instalar ahora**.

---

Este repositorio solo contiene instaladores; no incluye el código del programa.
